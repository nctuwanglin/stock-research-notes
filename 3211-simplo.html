① 催化劑分析 — 7/29法說會為何強調「毛利率重回正軌」?

  • 2026年初~8月股價全年振幅逾69%(277~469),隨BBU/VPU轉型題材與財報表現同步劇烈波動。
  • 2026年第1季EPS2.05元,季減18.04%,近四季EPS9.92元,顯示轉型初期的獲利波動性。
  • 2026年第2季EPS表現不如市場預期(季減約34%),反映高單價8kW/12kW新品尚未放量前的過渡期毛利率壓力。
  • 2026/07/29法說會:管理層明確表示BBU需求強勁,下半年營收將呈雙位數成長,毛利率重回正軌;高單價8kW與12kW VPU產品確認於Q4量產出貨,帶動平均銷售單價(ASP)提升;全年Non-IT營收占比預計突破50%,為公司關鍵轉型里程碑;全年AI Server VPU營收推估可達70億至80億元。
  • 2026年8月上旬公告7月合併營收12.29億元(依MOPS官方公告),月減3.10%、年增20.89%;累計1~7月營收80.65億元,年增21.66%。
  • 警訊市場容易忽略的資訊:①7月營收月減3.10%,是Q2財報不如預期後首個月度數字,尚未看到法說會宣稱的「H2雙位數成長」開始兌現,8月數字是更關鍵的驗證點;②2026年EPS估值在不同來源間存在顯著差異(12.1~13.21元),對應目標價也從400到550甚至800元不等,分歧程度大;③高單價8kW/12kW新品要到Q4才量產出貨,現階段的樂觀guidance仍需要2~3個月才能被財報數字驗證。

三句話總結

① 催化劑:7/29法說會釋出正向H2 guidance——BBU需求強勁、下半年營收雙位數成長、毛利率重回正軌,高單價8kW/12kW VPU產品確認Q4量產出貨,全年AI Server VPU營收推估70~80億元,Non-IT營收占比目標突破50%;惟Q2財報本身不如預期(季減約34%),7月營收月減3.10%,guidance尚待數字驗證。
② 估值:合理——自估法與較保守的法人目標價(400)高度一致(現價幾乎精準合理),僅較樂觀的法人目標價(550)顯示現價便宜逾27%但計算基礎較模糊;三年估值路徑呈現「今年持平、明年跳升」的時間結構,現階段投資是為明年的成長故事付費。
③ 結論:中性、靜待8kW/12kW新品Q4放量驗證——現價400.00落於Base區間上緣,上檔Bull +12%/Stretched +33%對下檔Bear -21%,風險報酬中性偏謹慎;可等待8月營收確認H2guidance開始兌現後再評估加碼,收盤跌破340即無條件出場。下一個驗證點是8月營收能否轉強,以及Q4新品量產時程是否如期。
